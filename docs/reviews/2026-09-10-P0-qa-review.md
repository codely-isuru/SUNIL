## Blockers — task/P0-contracts (owner: Solution Architect)

- **B1** `C1 §6` — fake spec covers `FakeToolAdapter` only; `PermissionHook`/`ParkHook`/`AuditHook` have no fake spec and tests 3–4 presuppose an unspecified grant-registration API. Tests unwritable without inventing behaviour.
- **B2** `C1 §2.1` — `approval` and `trace` parameter types undefined (`approval` is load-bearing at step 3: id str? C4 Approval? ApprovalBinding?).
- **B3** `C1 §2.1` step 3 vs `C4 §1/§3` — consume ownership contradictory: C4 has the continuation executor CAS to `consumed` before calling the Tool Manager; C1 has the manager validate the approval itself, and its constructor has **no consume hook**. Followed literally the approval is consumed twice → `approval_invalid` → nothing executes; C1 test 5 cannot pass. One owner; delete the other path.
- **B4** `C3 §2/§5` — required `WriteReceipt.audit_event_id` is unobtainable: nothing in `write(item, rules)` carries it; "provider only echoes it back" but there is nothing to echo. Add a parameter or field.
- **B5** `C3 §5` step 3 vs §4 — five mutually incompatible statements on dedupe/privacy-merge (unreachable `dedupe=False` clause; "stricter" described as widening; same condition both raises and upgrades; §4 "rejected, not averaged" vs §5 "keep the stricter"; genuine widening undefined). Test 3 does not disambiguate.
- **B6** cross-branch — ADR-032 + `ARCHITECTURE_V2 §5`/TB9/L-001 trace fix `5432`/`5678`/`WEB_ORIGIN :3000` vs platform reality **5433 / 5680 / 3001** (host ports; in-network `postgres:5432`/`n8n:5678` unchanged and correct). ADR-032's own consequences say fakes hardcode these addresses; the `WEB_ORIGIN` one is functional (403 `forbidden_client` by design). = Security review B1.
- **B7** cross-branch — `C2 §2` example `model: "claude-sonnet-4-5"` is the upstream id, not a gateway alias; live `/v1/models` = `claude-sonnet, claude-opus, claude-haiku, gpt-flagship, gpt-mini`. A request built to C2's example gets a LiteLLM 400. C2 must name the namespace; `config/models.yaml` ids must equal the gateway `model_name` set.
